# 🧩 Hash Checker v1.0
轻量图形化哈希校验工具，一键核对文件/文本完整性，防篡改、验文件指纹

## ✨ 功能亮点
📝 **文本比对**：两段文本快速计算SHA256，校验内容是否一致

📄 **单文件校验**：MD5/SHA1/SHA256/SHA512四算法，支持文件互比、粘贴哈希核对

📂 **文件夹差分扫描**：双目录批量对比，自动标记缺失/改动文件，单目录可导出全量哈希表

📊 **CSV报告导出**：完整哈希比对记录保存表格，方便存档核对

🎨 **自定义UI**：明暗系统三主题+三套配色，设置自动保存

⚡ **异步多线程**：大文件/海量文件夹扫描不卡顿，实时显示进度

## 📦 运行方式
### 源码运行
1. Python 3.11+
2. 安装依赖
```bash
pip install customtkinter
```
3. 启动程序
```bash
python main.py
```

### 打包程序
下载 Release 内压缩包，解压直接打开exe，无需Python环境

## 📁 项目文件
- `main.py`：程序全部代码
- `config.ini`：自动生成，存放界面主题配置
- `README.md`：项目说明
